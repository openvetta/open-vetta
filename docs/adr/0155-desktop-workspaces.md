# ADR-0155 桌面工作空间沿用项目和会话存储

## 背景

用户需要按工作内容整理桌面侧栏，并能在重启后继续上次的工作。项目和会话同时由桌面端、远程访问及自动化使用。移动磁盘目录或改变会话身份会影响这些入口，也会破坏已经保存的会话链接。

## 决策

桌面工作空间是本机侧栏的分组。Renderer 在版本化的本地配置中保存自定义空间、顺序、选中空间、单一归属和每个空间最近打开的项目或会话。项目按注册路径归属，独立普通会话按会话路径归属，独立 Team 会话按 Team 会话 ID 归属。缺少明确归属的数据回落到主空间，因此既有数据无需迁移。项目内的会话根据项目推导归属。

新建和移动只影响归属。删除分组时移除归属记录。用户确认同时移除项目时，桌面通过已有项目和会话服务分别处理。主进程会核验独立会话的类型和运行状态，专属目录按现有会话工作目录规则处理。共享目录和项目会话继续保留。

## 备选方案

可以把空间注册表并入主进程的项目配置，统一协调多个窗口的写入，并为远程端提供可同步的合同。第一版的入口和归属都是桌面本地的，沿用 Renderer 的本地存储和 storage 事件即可共享配置，也避免把空间概念扩展到移动端、IM 和自动化协议。若将来要跨设备同步，可读取当前配置后迁移归属记录，项目和会话身份可以继续沿用。

## 后果

全局搜索继续读取所有空间的项目和会话，打开时才切换空间。归档项目保留归属，空间消失后回到主空间。批量移除使用现有独立的项目和会话服务，遇到部分失败时用户可重试剩余内容。
