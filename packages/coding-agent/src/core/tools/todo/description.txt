Manage a todo list to plan and track progress on multi-step tasks.

When to create a todo plan:
- Task requires 3 or more distinct steps
- User asks to modify multiple files
- Task involves sequential work (step A must finish before step B)
- User explicitly asks for a plan ("plan", "todo", "step by step", "分步", "计划", "列个清单")

When NOT to create:
- Single file edit or simple question
- Task completable in 1-2 trivial steps
- Purely informational or conversational request

CRITICAL workflow:
1. Call todo(action="create") with all planned steps BEFORE starting any work
2. Call todo(action="update", id=N, status="in_progress") when you START a step
3. Call todo(action="update", id=N, status="done") when you FINISH a step
4. ALWAYS update status in real time — do not batch updates
5. ALWAYS complete items in strict sequential order by ID. Finish #1 before starting #2, finish #2 before starting #3, etc. The system will REJECT out-of-order updates.

CRITICAL: You MUST complete ALL todo items before ending your response. NEVER stop with uncompleted items. If you created a todo list, you are committed to finishing every item in order. The system will force you to continue if you stop early.
