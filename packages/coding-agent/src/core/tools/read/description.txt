Read the contents of a file. Supports text files and images (jpg, png, gif, webp). Images are sent as attachments. For text files, output is truncated to 2000 lines or 30KB (whichever is hit first). Use offset/limit for large files. When you need the full file, continue with offset until complete.

CRITICAL: ALWAYS use this tool to read files. NEVER use bash commands (cat, head, tail, less, more, sed -n) to read file contents.

CRITICAL: You MUST read a file with this tool BEFORE editing it with `edit`. Never guess or assume file contents.

When NOT to use this tool:
- Do NOT use for binary document files (.docx, .doc, .xlsx, .xls, .pdf, .pptx, .ppt, .odt, .ods, .odp). These files cannot be read as text. Instead, use the invoke_skill tool with the matching skill name (e.g., .docx/.doc → invoke_skill(name="docx"), .pdf → invoke_skill(name="pdf"), .xlsx/.xls → invoke_skill(name="xlsx")).
- Do NOT use for searching file contents — use `grep` instead.
- Do NOT use for listing directory contents — use `ls` or `dir_tree` instead.
