我想在packages\desktop-app这个客户端APP当中实现批量任务的功能。

# 任务

- 深入分析用户需求，你有充足的时间去实现这些需求，你需要制定充足且清晰的规划。
- 阅读spec\batch-tasks-spec.md文件，还有相关的实施文档，spec\exec\README.md，请你实现根据实施文档实现具体的功能。
- 分析用户提出的需求，拆解用户核心诉求，并转化为符合用户实际需求的 UI 操作逻辑。
- UI 需要符合基本操作逻辑，你需要梳理 UI 与需求的关联关系。

# 代码规范

- 代码应易于维护、模块化且具有易读性。模块、文件等应遵守功能的单一职责原则，避免在同一个文件当中堆砌功能无关的代码。
- 项目文件结构设计需要有架构设计，目录命名具有前瞻性以及功能命名意义，避免无意义，含糊的文件或文件夹命名。
- 将通用代码进行封装，在合适的环节或时机使用设计模式来提高扩展性和可维护性。
- 在合适的时候可以使用设计模式来提高扩展性和代码可维护性，但是避免过度设计。
- 使用更加简洁的 tailwindcss 而不是 css 类名属性。

# 约束

- 检查错误时使用 lint 和 tsc 来检查。

# 注意

- 当遇到方向性问题时需要告知我，比如因为实现困难导致更改方向。但是一些文件命名不需要告知我。
- UI 组件使用 packages\desktop-app\src\renderer\components\ui 下面的组件，如果有缺少一些重要的 UI 组件，比如 日期组件，输入组件等，可以告知我。但是类似于 Badge 这种简单的组件，可以不用通用 UI 组件，随用随造。
