# 需求

- 该定时任务的目的是定时将指定的提示词发送给大模型进行处理。
- 定时任务属于后台任务，只要应用没有关闭就可以执行，关闭之后则不考虑。
- 定时任务的执行与已有的对话实际上无任何区别，packages\desktop-app\src\renderer\components\Chat。只是后台任务不会进行 UI 渲染，但是如果查看该定时任务的执行过程，实际上可以基于已有的问答 UI 进行展示。
- 定时任务需要保存执行记录，你可以参考已有的实现。
