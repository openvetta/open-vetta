---
title: Use the Vetta Vivi desktop pet
description: Show the desktop pet from Settings and adjust its pinning and animation size.
---

Vetta Vivi is an independent transparent desktop window that follows the current session by switching animations, without text bubbles. It is not another Agent session; confirm important tasks in the main window.

Open **Settings → Vetta Vivi**.

## Display and window

| Setting | Description |
| --- | --- |
| Show desktop pet | Hides the pet window when disabled and keeps it hidden on the next launch |
| Keep on top | Floats above other windows when enabled; other windows can cover it when disabled |

Hold the pet to drag it. When the pointer is over the pet image, scroll to adjust the current animation size; different animations may remember their own size. Transparent areas outside the image try to pass mouse events through so they do not block work.

## Session status feedback

Vetta Vivi follows the current session through thinking, working, waiting for input, success, error, and paused states. It stays in the waiting animation while you answer a question, review a plan, grant a permission, or finish MCP setup. Success appears briefly before the pet returns to idle, while an error remains visible until the next turn starts.

To avoid flashing through several animations in a few seconds, rapid changes are coalesced to the latest state and each displayed state remains visible for about 3 seconds. Disabling automatic idle animations does not disable session status feedback.

## Development debugging

**Debug borders** show the window boundary, video region boundary, and size information. Enable them only for development diagnosis.

The current settings page exposes Show desktop pet, Keep on top, and Debug borders. Other internal fields, such as decorative asset lists, may not be visible in the UI; use the actual client behavior as the source of truth.

## Common issues

- **The pet covers work**: disable **Keep on top** or drag it to the edge of the screen.
- **The pet is too large or small**: put the pointer over the image and scroll.
- **It disappears after enabling**: toggle visibility again, check another monitor or an off-screen position, and confirm the Vetta main process is still running.
- **The animation does not follow the session**: confirm **Automatic animation switching** is on, then trigger a state change from the main window.
